# Demo Script

1. Open the dashboard and review total claims, high-risk claims, average risk, and unusual-claim count.
2. Inspect denial-rate charts and the highest-risk queue.
3. Open the claim worklist and select a high-risk claim.
4. Review risk band, denial probability, model drivers, unusual-claim status, and policy evidence.
5. Generate the analyst brief and point out the decision-support disclaimer.
6. Open the model page to show metrics and global drivers.
