# Claim Documentation Policy

This is a synthetic policy created for the HealthOps ClaimGuard AI demonstration and does not represent CMS, Evernorth, Cigna, or any real payer policy.

## DOC-01 Purpose
This demonstration policy defines documentation checks for analyst decision support.

## DOC-02 Required Support
Claims should include sufficient documentation to support the billed procedure, diagnosis relationship, service date, provider identity, and member eligibility.

## DOC-03 Incomplete Documentation
Incomplete documentation is a review signal. Analysts should request or verify missing documentation rather than treating the signal as an automatic denial.

## DOC-04 Review Procedure
Analysts should compare procedure complexity, diagnosis count, and available supporting records to determine whether additional documentation is needed.
